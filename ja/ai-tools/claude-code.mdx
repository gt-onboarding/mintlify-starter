Claude Code は Anthropic の公式 CLI ツールです。このガイドでは、ドキュメントを作成・保守するために Claude Code をセットアップする手順を説明します。

<div id="prerequisites">
  ## 前提条件
</div>

- 有効な Claude のサブスクリプション（Pro、Max、または API アクセス）

<div id="setup">
  ## セットアップ
</div>

1. Claude Code をグローバルにインストールします。

```bash
  npm install -g @anthropic-ai/claude-code
```

2. docs ディレクトリに移動します。
3. （任意）以下の `CLAUDE.md` ファイルをプロジェクトに追加します。
4. `claude` を実行して起動します。


<div id="create-claudemd">
  ## `CLAUDE.md` を作成する
</div>

ドキュメント用リポジトリのルートに `CLAUDE.md` ファイルを作成し、Claude Code にあなたのドキュメント標準を学習させます。

```markdown
# Mintlifyドキュメント

## 作業上の関係
- アイデアに対して異議を唱えることができます。これにより、より良いドキュメントが作成できます。その際は情報源を引用し、理由を説明してください
- 推測するのではなく、必ず明確化を求めてください
- 嘘をついたり、推測したり、情報を捏造したりしないでください

## プロジェクトコンテキスト
- フォーマット: YAMLフロントマター付きのMDXファイル
- 設定: ナビゲーション、テーマ、設定用のdocs.json
- コンポーネント: Mintlifyコンポーネント

## コンテンツ戦略
- ユーザーの成功に必要な分だけドキュメント化してください。多すぎず、少なすぎず
- 情報の正確性と使いやすさを優先してください
- 可能な限り、コンテンツを長期的に有効なものにしてください
- 新しいコンテンツを追加する前に、既存の情報を検索してください。戦略的な理由がない限り、重複を避けてください
- 一貫性を保つため、既存のパターンを確認してください
- 最小限の合理的な変更から始めてください

## ページのフロントマター要件
- title: 明確で説明的なページタイトル
- description: SEO/ナビゲーション用の簡潔な要約

## 執筆基準
- 二人称の文体（「あなた」）
- 手順コンテンツの冒頭に前提条件を記載
- 公開前にすべてのコード例をテストしてください
- 既存ページのスタイルとフォーマットに合わせてください
- 基本的なユースケースと高度なユースケースの両方を含めてください
- すべてのコードブロックに言語タグを付けてください
- すべての画像に代替テキストを付けてください
- 内部リンクには相対パスを使用してください

## Gitワークフロー
- コミット時に--no-verifyを使用しないでください
- 開始前に、コミットされていない変更の処理方法を確認してください
- 変更に適したブランチが明確に存在しない場合は、新しいブランチを作成してください
- 開発中は頻繁にコミットしてください
- pre-commitフックをスキップまたは無効化しないでください

## 禁止事項
- MDXファイルでフロントマターを省略しないでください
- 内部リンクに絶対URLを使用しないでください
- テストされていないコード例を含めないでください
- 推測しないでください。常に明確化を求めてください
```
